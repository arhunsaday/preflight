# ADK Desktop Implementation Plan

> For agentic workers: execute inline with executing-plans; user authorized autonomous work and pushes.

Goal: ship an Electron desktop client backed by the existing CLI with native multi-project management and all command capabilities.
Architecture: sandboxed React renderer → narrow validated preload → Electron controller → isolated CLI child process. Shared schema and transactions remain authoritative.
Tech stack: Electron, electron-vite, React, Radix Dialog, Lucide, electron-builder, Vitest, Playwright.
Spec: `docs/superpowers/specs/2026-10-04-desktop-design.md`.

## Global constraints

Preserve existing user changes. Never silently initialize selected projects. Preview all mutations before confirmation. No fabricated metrics/auth or server-enforced team roles. No renderer Node integration or arbitrary filesystem/shell IPC. Keep credentials out of renderer reads and project state. Push verified batches to existing branch.

## Review focus

- A project switches between preview and confirm: reject the receipt; never write in the new project.
- Replayed/expired preview or root/home override: reject in main, not only UI.
- Corrupt/missing config: show an actionable error without replacement.
- Installer/benchmark effects: show exact args and boundary before explicit run.
- Credential persistence: encrypted or session-only, never plaintext token in snapshot.
