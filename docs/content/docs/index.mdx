This site documents [Preflight](/docs/preflight), the tool: a CLI, a terminal
interface and a desktop app that keep an AI coding setup (Claude Code, Codex,
Cursor) declared, previewed, reversible and checked.

Preflight ships no content. Skills, plugins, hooks, subagents, loadouts and the
global `CLAUDE.md` live in a content repository that Preflight reads as a
[source](/docs/preflight/sources). Mine is
[arhunsaday/agent-kit](https://github.com/arhunsaday/agent-kit); its guides
(skills, hooks, MCP servers, workflows, other agents) are in its
[`guides/`](https://github.com/arhunsaday/agent-kit/tree/main/guides) folder.
