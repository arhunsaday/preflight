<Callout type="info">
A Preflight desktop app is planned. It does not exist yet, and there is no date.
</Callout>

The intent is the same engine behind a windowed interface: browse and inspect a
setup, preview a change as a diff, apply it, and roll it back, without a
terminal. The CLI and [terminal interface](/docs/preflight/tui) are the
supported surfaces today, and anything the app does will be a command you can
also run there.

This page will describe the app once there is something to install.
