Commands print JSON on stdout; errors go to stderr with a nonzero exit code.
Global options: `--dry-run`, `--json`, `--root <path>`, `--home <path>`, and
`--global` to target the shared global configuration at `~/.preflight/global`.
`preflight <command> --help` is authoritative. New here? Follow the [Quickstart](/docs/preflight/quickstart).

## Setup and state

| Command | Purpose |
| --- | --- |
| `init` | create a project configuration |
| `list` | list desired resources |
| `validate <file>` | validate a desired-state configuration |
| `profiles` | create, switch and diff profiles |
| `sync` | reconcile desired state to harness files |
| `audit` | show the append-only change history |

## Inspect and adopt

| Command | Purpose |
| --- | --- |
| `detect` | read installed harness resources |
| `unmanaged` | what a harness holds that the profile does not manage |
| `adopt <id>` | manage a detected resource where it already lives |
| `inspect <id>`, `inspect-json <json>` | content, permissions, configuration, provenance |
| `doctor [--connect] [--days n] [--processes] [--measure] [--no-transcripts]` | findings by severity with fix and token cost; see [Doctor](./doctor) |
| `instructions lint [file]` / `instructions draft [--scope] [--agent] [--write]` | lint or draft CLAUDE.md / AGENTS.md; see [Doctor](./doctor#instructions) |
| `verify <id> [--connect]` | static check, or initialise the MCP server and list tools |

## Change resources

| Command | Purpose |
| --- | --- |
| `create <file>`, `create-json <json>` | add a resource |
| `update <id> <file>`, `update-json` | patch a resource |
| `delete <id>` | remove it and its managed wiring |
| `fork <id> <new-id>` | duplicate under a new identity |
| `move <id> <scope>` | switch between global and project scope |
| `rollback`, `recover` | reverse the latest transaction, or restore an interrupted one |

## Find and install

| Command | Purpose |
| --- | --- |
| `source add\|list\|show\|update\|remove` | content sources the catalogue and loadouts come from; see [Sources](/docs/preflight/sources) |
| `search [query]` | catalogue search; `--source`, `--type`, `--online`, `--github <owner/repo>`, `--catalog <dir>` choose and add sources |
| `catalog-inspect <id>`, `catalog-add <id>` | inspect, then add an item from a source |
| `catalog build <dir>` | write a content repository's `catalog/index.json`; `--check` in CI |
| `inspect-file <file>` | validate a catalogue resource file |
| `install <id>` | print the package-manager plan; `--execute` runs it |

## Measure

| Command | Purpose |
| --- | --- |
| `usage [--by session\|skill\|project\|model\|day\|agent] [--since 30d] [--until day] [--agent claude-code\|codex\|all] [--project root]` | tokens, cache hit rate and cost estimate from local Claude Code and Codex transcripts; see [Usage](/docs/preflight/usage) |
| `prune` | propose unused skills (never deletes) |
| `reflect [--since 30d] [--top 5] [--project root] [--no-write]`, `reflect show <session>`, `reflect lessons`, `reflect lesson add\|verdict\|dismiss` | rank struggling sessions, write redacted trajectories and keep lessons; see [Reflect](/docs/preflight/reflect) |
| `context [--mode potential\|catalogue] [--agent claude-code\|cursor\|codex] [--scope global\|project]` | estimated instruction size; see [Context map](/docs/preflight/context-map) |
| `bench scaffold\|run\|compare` | local A/B runs of two configurations |

| Command | Purpose |
| --- | --- |
| `share`, `apply`, `revoke` | see [Sharing](/docs/preflight/sharing) |

## Account and teams

| Command | Purpose |
| --- | --- |
| `auth login [--service <url>] [--no-browser]` | browser sign-in (GitHub or Google); the API token goes to the OS keychain |
| `auth status`, `auth logout` | show or revoke the current sign-in |
| `auth tokens`, `auth revoke <token-id>` | list or revoke your API tokens |
| `team list\|create\|members` | teams (Clerk Organizations) |
| `team invite <org> <email> [--role admin\|member]` | Clerk emails the invitation |
| `team invitations <org>`, `team cancel-invitation <id>` | invitations you sent (admins) |
| `inbox` (or `team inbox`), `team accept\|reject <id>` | invitations for you |
| `team role <org> <user> admin\|member`, `team remove`, `team leave` | membership changes |
| `team shares <org>` | shares published to a team |

`auth login` opens your browser on the Preflight sign-in page and listens on
`127.0.0.1` for the redirect. With `--no-browser`, it prints the URL and you
paste the code that the page shows. Tokens expire after 90 days without use.

Backend setup: [Cloudflare backend and accounts](/docs/preflight/cloudflare-backend).

## Environment

| Variable | Used for |
| --- | --- |
| `PREFLIGHT_HOME` | default harness home |
| `PREFLIGHT_API_URL` | the backend (default `https://api.preflight.arhun.fr`) |
| `PREFLIGHT_SHARE_URL`, `PREFLIGHT_SHARE_TOKEN` | share with an explicit service and API token instead of the signed-in account |
| `PREFLIGHT_METRICS` | a benchmark task writes tokens and interventions here |

Worked examples for each group: [PREFLIGHT.md](https://github.com/arhunsaday/preflight/blob/main/PREFLIGHT.md).
