## How to evaluate before installing

A skill is a prompt running with your tool permissions. Read `SKILL.md` first —
same reflex as reading a shell script before `| bash`.

1. **`allowed-tools`** — does it ask for more than its job needs?
2. **Network or out-of-project writes** — why?
3. **Commit history** — real iteration, or one bulk drop?
4. **Description quality** — a vague description means it fires at random, or
   never
