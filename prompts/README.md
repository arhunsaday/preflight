# Prompts

Reusable prompt text that is **not** a skill and **not** a slash command.

| | Fires when | Lives in |
| --- | --- | --- |
| Skill | the model matches its description | `claude-code/skills/` |
| Slash command | you type `/name` | `claude-code/commands/` |
| **Prompt** | you paste it | here |

Use this folder for text you send to a *web* chat, another vendor's tool, or a
colleague — anywhere the skill and command machinery does not exist. If you find
yourself pasting one of these more than twice in Claude Code, promote it to a
slash command.
